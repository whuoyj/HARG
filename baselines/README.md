# Baseline

This repository provides the implementation for the baseline methods reproduced on two datasets: the MOMA dataset and the MOMA-LRG dataset.

## VideoMAEv2 and AMS-Net

Both [VideoMAEv2](https://github.com/open-mmlab/mmaction2) and [AMS-Net](https://github.com/open-mmlab/mmaction2) are independent methods designed for action recognition, and both can be implemented and used within the [MMAction2](https://github.com/open-mmlab/mmaction2) framework. The modifications made to these methods are based on the integration within MMAction2.

### Requirements

This project is built on top of MMAction2 , which provides a flexible framework for video action recognition.You can follow the official installation guide for [MMAction2](https://github.com/open-mmlab/mmaction2) to set up the environment.

## MAR

The [MAR](https://github.com/alibaba-mmai-research/Masked-Action-Recognition) method is directly modified from its original code. 

### Requirements

The requirements for the MAR method are directly based on the original code. You can refer to the original [MAR](https://github.com/alibaba-mmai-research/Masked-Action-Recognition) repository for installation instructions and dependencies.

## OR2G

We provide the implementation of the OR2G method for the MOMA dataset and the MOMA-LRG dataset.

### Requirements

The requirements for the OR2G method are same with HARG.
